# data/pilot

`pilot.csv`: 15 requirement cho pilot (plan mục 9), mỗi tài liệu một câu, **không** trùng tập đánh giá, smoke hay cặp ghim. Sinh bởi `npm run data:build` với seed riêng; `target_diagram` là heuristic, Thành viên 1 kiểm tra trước khi chạy pilot. Kết quả pilot không đưa vào kết quả confirmatory.
